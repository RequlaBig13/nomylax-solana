# Agent strategy

Nomylax does not require an agent to use a specific model or framework. An adapter only needs to produce an economic intent with amount, SOL token identifier, Solana recipient and purpose.

The agent may reason freely about the action. The Financial Constitution remains outside that reasoning loop.

The contest demo ships with a deterministic demo adapter so judges can test the complete product without provisioning external agent infrastructure. An HTTP adapter is available for real agents.

Longer term, x402 / machine-payment adapters are a natural extension once the core Solana settlement and Guard program are proven.
