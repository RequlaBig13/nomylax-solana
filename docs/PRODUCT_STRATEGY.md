# Product strategy

## Wedge

Autonomous software increasingly needs to buy data, inference, infrastructure and services. The first Nomylax wedge is controlled machine spending: owners define a financial boundary and agents operate inside it.

## Differentiation

Nomylax is not positioned as another agent wallet. The product combines:

- a human-readable Financial Constitution
- deterministic enforcement
- Shadow Lab before activation
- explainable risk
- emergency Safe Mode
- verifiable Solana settlement evidence
- an AI copilot that explains without authorizing

## Expansion

After the SOL-first MVP:

1. SPL / USDC delegated authority
2. deployed Nomylax Guard program
3. x402 and agentic-payment adapters
4. protocol-aware transaction inspection
5. team policies and multi-user approvals
6. enterprise audit export and monitoring
