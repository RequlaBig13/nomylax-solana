# Business Model

The business model is infrastructure-oriented. This document describes packaging direction, not existing revenue.

- **Free / test:** local development, Shadow Mode and basic controls for evaluating an agent integration.
- **Developer:** API access, higher usage limits, integration tooling and richer operational telemetry.
- **Pro:** advanced policies, monitoring, risk analysis, audit exports and approval workflows.
- **Teams / enterprise:** shared policy administration, organization controls, compliance/audit features and support.
- **Protocol / infrastructure:** integration-oriented commercial arrangements where a protocol or platform embeds Nomylax controls.

## Submission fields
**Token:** not declared. The core control-plane architecture does not require a token claim.

**Revenue share:** not declared. No percentage is represented by this repository.

**Funding target:** not declared. A real target should be added only if the builder has one.

These explicit statuses are intentional: missing commercial information should not be replaced with fabricated numbers.
