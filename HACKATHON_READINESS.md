# Road to Colosseum readiness

Use this as the final submission gate.

## Product

- [ ] Landing page communicates the problem in under 15 seconds
- [ ] Wallet connection works with at least Phantom and one other Wallet Standard wallet
- [ ] Solana ownership signature works
- [ ] Onboarding completes without manual database edits
- [ ] Financial Constitution changes affect verdicts
- [ ] Shadow Lab produces a real behavior report
- [ ] Intent Lab demonstrates both an approval and a block
- [ ] Live approval settles on Devnet from the connected wallet
- [ ] Returned signature opens in Solana Explorer
- [ ] Spend counters update only after settlement
- [ ] Safe Mode can be demonstrated
- [ ] Anthropic Copilot works when a key is configured and core controls work without it

## Solana evidence

- [ ] Devnet network shown clearly
- [ ] At least 3 successful live demo transactions recorded
- [ ] At least 1 transaction memo contains a Nomylax decision reference
- [ ] Public wallet / transaction evidence contains no secrets
- [ ] If Guard is deployed: real program ID recorded
- [ ] If Guard is deployed: policy PDA and Guard payment transaction recorded
- [ ] No placeholder address is presented as deployment evidence

## Engineering

- [ ] `npm run typecheck`
- [ ] `npm run lint`
- [ ] `npm run test`
- [ ] `npm run build`
- [ ] no `.env.local` in Git
- [ ] all previously exposed keys rotated
- [ ] public README setup works from a fresh clone
- [ ] mobile layout checked
- [ ] failure states tested with wallet rejection and invalid recipient

## Submission assets

- [ ] Project name and tagline final
- [ ] Problem and Product answer final
- [ ] Solana Integration answer final
- [ ] Live MVP link
- [ ] 2 to 3 minute demo video
- [ ] public GitHub repository
- [ ] deployment network listed as Devnet or Mainnet honestly
- [ ] transaction evidence included
- [ ] Colosseum registration complete
- [ ] Germany selected only if that accurately reflects the team's actual registration circumstances
- [ ] Colosseum project page created
